# Keyball61 для ZMK (пока только правая половина)

Контроллер: Pro Micro nRF52840 (совместим с nice!nano). Правая половина с трекболом PMW3360.

## Как собрать
1. Создайте на GitHub новый пустой репозиторий и загрузите в него всё содержимое этой папки
   (включая скрытую папку `.github`).
2. Откройте вкладку **Actions**, дождитесь окончания сборки «Build ZMK firmware».
3. Скачайте артефакт `firmware`, в нём файлы `.uf2`.

## Как прошить
1. Дважды быстро нажмите кнопку Reset на контроллере: появится диск NICENANO.
2. Сначала один раз прошейте `settings_reset-nice_nano-zmk.uf2`, затем (после повторного входа
   в режим загрузчика) `keyball61_right-nice_nano-zmk.uf2`.
3. Подключите по USB или сопоставьте по Bluetooth («Keyball61»).
   Bluetooth-слоты и сброс сопряжения находятся на слое 3 (верхний левый ряд).

## Что проверить после первой прошивки
- Нажимаются ли клавиши правой половины и совпадают ли с QMK-раскладкой.
- Двигается ли курсор в нужную сторону.
- Слой 3 (клавиша `LT(3, LANG1)`): шарик должен прокручивать страницу.

## Если что-то работает не так
- Курсор идёт не туда: в `keyball61_right.overlay` раскомментируйте `rotate-90;`
  или добавьте инверсию осей (см. документацию ZMK, раздел Input Processors -> Transformer).
- Прокрутка слишком быстрая/медленная: измените `1 4` в `input-processors` слоя `scroller`
  (например, `1 6` медленнее, `1 3` быстрее).
- Ни одна клавиша не нажимается или нажимаются «не те»: напишите, пришлю вариант матрицы с
  обратной полярностью.
