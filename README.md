# Keyball61 для ZMK: донгл + правая половина

Устройства (все на Pro Micro nRF52840):
- **Донгл** (`keyball61_dongle`): вставляется в USB компьютера, всё общение с ПК идёт через него.
- **Правая половина** (`keyball61_right`): с трекболом, подключается к донглу по Bluetooth.
- **Левая половина** (`keyball61_left`): без трекбола, тоже подключается к донглу.
  Ни одна половина к компьютеру напрямую не подключается.

## Как прошить (важно соблюдать порядок)
1. Соберите проект в GitHub Actions (вкладка Actions), скачайте артефакт.
2. На КАЖДОМ контроллере (донгл, правая и левая половины) прошейте `settings_reset-nice_nano-zmk.uf2`
   (двойное нажатие Reset, скопировать файл на диск NICENANO).
3. На донгл прошейте `keyball61_dongle-nice_nano-zmk.uf2`.
4. На правую половину прошейте `keyball61_right-nice_nano-zmk.uf2`.
5. Прошейте левую половину `keyball61_left-nice_nano-zmk.uf2`.
6. Включите обе половины рядом с донглом: они соединятся сами. Подключать ничего вручную не нужно.

Без донгла клавиатура работать не будет.

## Раскладка
Править нужно только `config/keyball61.keymap` (файл `keyball61_dongle.keymap` просто подключает его).
